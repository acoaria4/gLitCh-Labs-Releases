# Icon assets

Selected transparent PNGs are in `finalized-icons/`:

- `aura-solar-embrace-ivory.png`: active AURA website icon.
- `aura-solar-embrace-obsidian.png`: dark AURA alternative.
- `expenses-champagne-on-obsidian.png`: active Expenses website icon.
- `lumen-metallic-enamel.png`: active Lumen website icon; original preserved at `assets/lumen-icon.png`.
- `glitchlabs-polished-platinum.png`: active studio website icon; original preserved at `assets/glitchlabs-icon.png`.

All five are native 1254 × 1254 RGBA PNGs. Their full boundaries are preserved without clipping. The product website references, favicons, sharing metadata and the Expenses entry in Social Composer use this folder. Studio headers, footers, favicons and Social Composer use polished platinum; existing wordmark artwork is retained.

Draft boards and rejected variants stay under local `generations/` (gitignored). The original Lumen and studio artwork remain at their existing paths.
