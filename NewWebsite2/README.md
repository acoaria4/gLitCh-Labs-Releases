# gLitCh Labs — Flagship

React + Vite + TypeScript experience for gLitCh Labs.

## Stack

- React 19 / TypeScript / Vite
- GSAP + ScrollTrigger + Lenis
- Three.js (hero artifact)
- Canvas 2D (material laboratory)
- Geist Variable + Geist Mono

## Develop

```bash
npm install
npm run dev
```

Opens on port `5174`.

## Build

```bash
npm run build
npm run preview
```

## Brand

Logo files in `public/brand/` — the only brand assets used.
