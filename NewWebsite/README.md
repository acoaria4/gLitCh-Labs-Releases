# gLitCh Labs — NewWebsite

Flagship digital laboratory experience for gLitCh Labs.

## Stack

- Vite + React + TypeScript
- GSAP + ScrollTrigger + Lenis
- Three.js (hero field + material playground)
- Geist Sans / Geist Mono

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

Dev server defaults to port **5174**.
